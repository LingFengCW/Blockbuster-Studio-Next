# 便捷性路线图（Convenience Roadmap）

> 本册汇总「已落地」与「规划中」的便捷特性，避免空壳。规划项均需在后续迭代立项，不在此版本假装实现。

## ✅ 已落地（本版本）

| 类别 | 功能 |
|---|---|
| 命令面板 | Ctrl+K 模糊过滤、键盘导航、29 条命令 |
| 快捷键 | 空格/←→/Home/End/=−/M/S/Ctrl+K/?/Esc + 既有 Ctrl+R/./F2/K |
| 工作区 | 动画/剪辑/预览 三预设 + 重置，localStorage 持久化；**预设切换现真正改变面板尺寸**（原 `applyWorkspace` 误写被 flex-basis 覆盖的 `--asset-w/--tl-h` 导致无效，已改为直接驱动 `--left-w/--bottom-h`）；**分隔条拖拽尺寸按工作区独立持久化**（`bbs_ws_sizes`，重启/切换工作区各自恢复，对标 Premiere 面板布局记忆） |
| 时间轴 | 缩放(按钮/=−/适应)、缩放指示%、吸附开关（**现已真实生效**：拖拽 clip 吸附到标记/他轨端点/播放头，带蓝色吸附参考线）、标记(M/按钮/点击跳帧，右键删除，持久化到 `Film.markers`)、时间码 HH:MM:SS:FF |
| 轨道头 | 每条角色轨头部 👁 显隐 / 🔒 锁定按钮；显隐复用既有 `Replay.enabled`（BaseFilmController 已按它跳过渲染），锁定复用既有 `Replay.locked` 并守卫 `moveClip`/`resizeClip` 与前端拖拽（锁定轨禁止拖动剪辑） |
| 状态栏 | 时间码 + 播放头/时长 + 状态(录制/播放/就绪) + 自动保存脉冲指示 |
| 引导 | 首次 coach-mark 漫游、帮助菜单(引导/快捷键/教程/命令面板)、自定义 tooltip、试用警告 |
| 主题/视觉 | 明/暗主题切换（CSS 变量覆盖 + localStorage 持久化 + 标题栏「主题」按钮） |
| 资源库 | 搜索/过滤框（按 `.lbl` 文本实时过滤，空分组自动隐藏） |
| 时间轴 | 缩放滑块（0.25×–8×，与放大/缩小/适应三处联动）、右键上下文菜单（标记/吸附/适应/删除选中剪辑）、**总览条/mini-map**（全时长缩略 + 点击跳转）、**面板最大化**（素材库/视口/时间轴单面板展开，localStorage 持久化） |
| 命令面板 | 原有 29 条 + **「最近使用」分组**（localStorage 记录最近 5 条） |

## ⬜ 规划中（roadmap，需单独立项）

### 时间轴深度
- **持久化标记**—— ✅已落地（见「已落地·时间轴」：`Film.markers` ValueList 持久化 + `addMarker`/`removeMarker` 后端动作 + 前端从 `s.markers` 同步 + 右键删除）。
- **真实吸附**—— ✅已落地（见「已落地·时间轴」：拖拽 clip 吸附到标记/他轨端点/播放头，像素阈值内生效，蓝色吸附参考线 `#snapLine` 实时显示）。
- **波纹编辑 (B) / 剃刀 (C/Ctrl+K)**：后端 timeline 模型支持。
- **轨道头**—— ✅已落地（见「已落地·轨道头」：显隐 👁 + 锁定 🔒 两个按钮；喇叭/静音因本模组音频语义不明确未做，避免空壳；`enabled`/`locked` 均为 `Replay` 既有字段，仅补齐 UI 与守卫）。
- **J-K-L 梭动**：前端可视反馈 + 后端变速播放。

### 命令面板增强
- 命令分组/图标、最近使用、可搜索后端动作。
- 可视化快捷键编辑器（AE 式三色 + 冲突检测 + 另存预设）。

### 导航与概览
- **时间轴 mini-map / 总览条**（Premiere navigator）：快速缩放定位—— ✅已落地（见「已落地·时间轴」：全时长缩略 + 点击跳转；拖拽视窗指示待后续）。
- 缩放滑块（底部）—— ✅已落地（见「已落地·时间轴」）。

### 工作区增强
- **拖拽改尺寸并写入预设**—— ✅已落地（见「已落地·工作区」：分隔条拖拽按工作区持久化到 `bbs_ws_sizes`）。
- 多命名预设；单面板最大化—— ✅已落地（见「已落地·时间轴」：素材库/视口/时间轴单面板展开）。

### 编辑便捷
- 右键时间轴上下文菜单（加标记/缩放/吸附/分割）—— ✅已落地（标记/吸附/适应/删除选中；分割待后端支持）。
- 项目模板（新建项目带默认场景/角色结构）。
- 批量重命名、资源库搜索过滤—— ✅已落地（见「已落地·资源库」）。
- 自动保存版本历史（DaVinci Live Save + Project Backups 式回滚）。

### 视觉
- 明/暗主题切换（CSS 变量已就绪，加切换器即可）—— ✅已落地（见「已落地·主题/视觉」）。
- 最近项目快速打开（对标 Premiere Home）。

## 不在范围

- 改变既有 Java 后端语义或新增后端契约（本次仅在既有 `send()` 契约上做前端便捷层）。
- 任何以 TODO/空壳方式占位的功能——规划项显式列入 roadmap，不实装。
