# 快捷键体系 + 命令面板（Command Palette）

## 基准：专业软件怎么做

- **Premiere / 通用 NLE**：`空格` 播放、`V` 选择、`C` 剃刀、`B` 波纹、`I/O` 入出点、`M` 标记、`Ctrl+K` 加编辑点、`↑/↓` 上/下编辑点、`←/→` 逐帧。
- **After Effects**：`Edit → Keyboard Shortcuts`（或 `Ctrl+Alt+'`）打开**可视化快捷键编辑器**，三色编码——灰=未分配、紫=应用级、绿=面板级；支持搜索、拖拽分配、冲突警告、另存预设。
- **VSCode / Sublime / Fusion**：`Ctrl+Shift+P` / `Ctrl+K` 命令面板，模糊过滤 + 键盘导航，低频操作不用翻菜单。
- **DaVinci**：`Shift+1~7` 切 Page。

**共同规律**：① 高频操作必须键盘可达；② 快捷键要可发现（菜单提示/tooltip/列表）；③ 低频操作交给命令面板兜底。

## 我们的设计

### 已落地的快捷键

| 键 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `←` / `→` | 播放头逐帧后退 / 前进 |
| `Home` / `End` | 跳到开头 / 结尾 |
| `=` / `-` | 时间轴放大 / 缩小 |
| `M` | 在播放头添加时间轴标记 |
| `S` | 切换吸附 |
| `Ctrl+K` | 打开 / 关闭命令面板 |
| `?` | 打开命令面板（键盘流） |
| `Esc` | 关闭菜单/命令面板/教程 |
| `Delete/Backspace` | 删除选中关键帧/剪辑/角色（原有关联逻辑保留） |

> 注：`Ctrl+R`（录制）、`.`（解除伪装）、`F2`（截图）、`K`（加关键帧）为既有快捷键，已在状态栏与「快捷键一览」列出。

### 命令面板（Ctrl+K）

- 输入关键字模糊过滤（匹配中文标签 + 英文关键字 `kw`）。
- `↑/↓` 选择，`Enter` 执行，`Esc` 关闭。
- 收录 **29 条**常用命令：播放、跳帧、新建（场景/角色/实体/相机/序列）、保存、撤销/重做、录制、动作编辑器、截图、标记、缩放/适应、吸附、工作区切换、重置布局、引导/快捷键/教程、退出。
- 每条命令的 `run` 直接走既有 `send()` 或前端便捷函数，**无新增后端契约**。

### 快捷键「可发现性」

- 状态栏常驻快捷键提示。
- 帮助菜单「快捷键一览」模态列出全部。
- 工具栏按钮带 `title`，并接**自定义 tooltip**（`#tipBubble`，悬浮显示气泡，比原生 title 更及时、可定位）。

## 规划（不在本次范围）

- 可视化快捷键编辑器（AE 式三色 + 冲突检测 + 另存预设）——工作量较大，需前端配置层 + 持久化。
- 快捷键自定义重绑。
- J-K-L 梭动的前端可视反馈。
