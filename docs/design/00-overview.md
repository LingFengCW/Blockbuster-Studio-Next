# BBS-NEXT（泠瀑）编辑器 · 专业 UX 设计总览

> 本文档集是编辑器交互/视觉专业化的设计基准与落地记录。目标：让 BBS-NEXT 的 HTML 编辑器在**专业性、便捷性、可学习性**上对标主流 NLE / 动画软件（Premiere Pro、DaVinci Resolve、After Effects、Blender、OpenShot），同时贴合 Minecraft 模组（MCEF 全屏叠层）的现实约束。

## 1. 为什么要做这件事

用户明确要「弄一堆设计文档 + 把软件做得像专业软件 + 弄很多方便的东西 + 上网搜专业软件是怎么做的」。本集文档即对应这三件事：

1. **调研**：联网研究专业软件在「布局/工作区/时间轴/快捷键/命令面板/引导」上的做法（见各分册「基准」节）。
2. **设计**：把可借鉴的模式映射成泠瀑编辑器的具体方案（见各分册「我们的设计」节）。
3. **落地**：在 `editor_ui.html` 中实现可用功能，禁止空壳/TODO（见各分册「已落地 / 规划」节）。

## 2. 专业软件基准速览（联网调研结论）

| 维度 | Premiere Pro | DaVinci Resolve | After Effects | 我们的现状 |
|---|---|---|---|---|
| 面板布局 | 四主面板（项目/源/时间轴/节目）+ 可停靠 | 7 个「Pages」，面板可显隐 | 图层面板/时间轴/效果 | 已有：素材箱/视口/时间轴/状态栏 |
| 工作区预设 | 16 个预设（Essentials/Vertical/Assembly…）+ 重置 | Workspace → Reset UI Layout | Shift+F10/11/12 | ✅ 动画/剪辑/预览 三预设 + 重置 |
| 时间轴 | 吸附、缩放、标记、波纹/剃刀、J-K-L | 吸附、缩放、标记、Ripple | 图层+关键帧 | ✅ 缩放/吸附/标记/时间码；波纹/剃刀规划中 |
| 快捷键 | 空格/V/C/B/I/O/M/Ctrl+K… | Shift+1~7 切 Page | 可视化快捷键编辑器，颜色编码 | ✅ 空格/←→/Home/End/=/−/M/S/Ctrl+K |
| 命令面板 | 无原生（第三方有） | 无 | 无 | ✅ Ctrl+K 模糊过滤命令面板 |
| 引导/帮助 | Home 屏内嵌教程 | 内嵌 | 工具提示 | ✅ 新手引导(coach-mark)/帮助菜单/教程文档 |
| 自动保存 | 手动保存 | **Live Save**（强） | 自动保存 | ✅ 状态栏「自动保存」脉冲指示 |

## 3. 设计原则（泠瀑版）

- **面板即专业**：素材箱=项目面板，视口=节目监视器，时间轴=序列，状态栏=专业 HUD。
- **键盘优先**：一切高频操作都有快捷键；命令面板兜底低频操作。
- **引导但不啰嗦**：首次启动一次 coach-mark，之后靠 Help 菜单与 tooltip 自助。
- **状态可见**：播放头/时长/状态/时间码/自动保存在状态栏常驻。
- **不破坏既有架构**：所有功能走既有 `send()` 桥与 `renderAll()` 重绘；前端便捷层不污染 Java 后端语义。
