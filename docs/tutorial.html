入门 进入编辑器与工作区

BBS-NEXT 的编辑器是一个覆盖在原生 Dashboard 之上的全屏 HTML 界面（基于 MCEF / Chromium），通过 Java↔JS 桥接与游戏世界通信。

界面四大区块
  • 顶栏 + 主菜单栏：工程名、帧率时长、文件/编辑/视图…功能入口。
  • 左侧资源库：场景、角色、动作模板、音频等素材，支持右键新建与导入。
  • 中央预览视口：实时 3D 主相机画面，含网格、中心线、截图等工具。
  • 底部时间轴：多轨道剪辑核心区，编排场景、相机、音频与关键帧。
图：编辑器工作区结构示意

建议先用首页的 UI 引导 走一遍交互式认识，再回来阅读细节。

基础 场景与角色：从资源库新建

所有内容都从资源库开始。右键空白处或分组即可新建。

新建场景
  1. 在左侧资源库右键 → 新建 → 场景。
  2. 命名后会生成 .scenebbs 场景工程，出现在「场景工程」分组。
  3. 双击或右键「打开」进入该场景进行编辑。
新建角色
  1. 资源库右键 → 新建 → 实体（玩家实体 / 盔甲架 / 僵尸 / 自定义模型实体）。
  2. 角色即「无限角色」中的一员，可套用形态系统变身任意实体或模型方块。
提示：也可导入外部资源——音频（wav/ogg）、旧版 .bban 动画、或图片序列帧，作为素材直接使用。
图：资源库右键菜单 → 新建内容

核心 时间轴剪辑：轨道、剪辑块与播放头

时间轴是专业非线性编辑（NLE）范式，对标 Premiere / Blender 的多轨道结构。

轨道类型

  • 场景轨道：放置场景剪辑块，决定何时出现哪个场景。
  • 全局相机轨道：编排相机走位与运镜。
  • 音频轨道：波形剪辑，可静音 / 锁定。
  • 时间标记轨道：关键事件标记点。

基本操作

把素材拖到时间轴
  1. 从资源库把场景 / 角色 / 音频拖到对应轨道的 剪辑块泳道。
  2. 拖动剪辑块两端可裁剪长度，拖动中间可移动位置。
  3. 右键剪辑块可拆分、波纹删除、设置速度（整体拉伸 / 倒放 / 分段变速）。
// 轨道模型（示意） 场景轨道 : [==== 主城场景 ====][== 黄昏海岸 ==] 相机轨道 : [======== 相机走位 A ========] 音频轨道 : [====== 背景音乐 ======] 标记轨道 : [★ 关键标记] ^播放头
播放头：拖动时间轴顶部的红色竖线即可逐帧定位；配合视口的「帧步进」按钮（◀ ▶）精修。

预览 动作序列与实时预览播放

编排好轨道后，进入世界即可实时预览：角色按关键帧动画、相机按走位运动。

预览播放流程
  1. 在资源库选中一个已绑定世界的场景。
  2. 点击主视口工具条的 ▶ 播放 —— 自动进入游戏世界并启动 FirstPersonFilmController 播放。
  3. 角色动画、相机运动同步播放；点 ⏸ 暂停 或退出预览即停止释放。
图：预览视口与播放控制
已知边界：已在世界内时再点另一场景不会自动切换世界（enterSceneWorld 的 mc.level 守卫不重复开）。如需「预览中切场景自动切换」，可后续反馈主理人。

进阶 关键帧曲线与材质时间轴

专业感的来源：关键帧 + 插值曲线，对标 Blender 的曲线编辑器。

关键帧

  • 选中目标后按 K 添加关键帧，记录当前位置 / 旋转 / 缩放 / 轨迹。
  • 插值模式：线性、缓入、缓出、贝塞尔（自动 / 平滑）。
  • 打开曲线编辑器面板可像专业 DCC 一样拖拽缓动曲线。

材质时间轴

除角色动作外，材质 / 模型方块也拥有独立时间轴，可随时间驱动颜色、可见性、形状等属性，构建更复杂的视觉变化（如昼夜渐变、物体生长）。

设计取舍：把「动作序列」与「材质属性」都做成时间轴驱动，既统一了工作流，也降低了学习成本——编辑器交互范式始终一致。

收尾 导出与渲染

完成编排后输出成片。

导出路径
  1. 菜单 文件 → 导出：导出场景 .scenebbs / 序列 .seqbbs / PNG 序列帧。
  2. 菜单 渲染：管理渲染队列、输出参数预设，可开启后台渲染。
  3. 快捷键 F2 截图导出当前帧。
# 典型输出 序列成片 → .seqbbs（可在游戏内再次打开编辑） 帧序列 → PNG 序列帧（供外部合成） 当前帧 → F2 截图
