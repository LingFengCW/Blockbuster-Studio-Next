Quick Start

分步快速上手（5 步）

从进入编辑器到导出成片，最短路径如下。

进入编辑器

在游戏中打开 BBS-NEXT 编辑器（基于 MCEF / Chromium 的全屏 HTML 界面覆盖在原生 Dashboard 上）。

资源库右键新建

在左侧资源库面板右键 → 新建场景与角色（实体 / 模型方块 / 粒子等）。

拖拽素材到时间轴

把场景、相机、音频等素材拖入底部时间轴，按轨道排列剪辑块与关键帧。

预览播放

点击主视口工具条的 ▶ 播放，实时查看 3D 预览与相机运动；用播放头精确定位。

导出

通过菜单 渲染 / 文件 → 导出 输出序列或 PNG 序列帧，完成成片。

Why BBS-NEXT

对标专业软件的设计取舍

BBS-NEXT 把专业 NLE（非线性编辑）与 3D DCC 的核心范式搬进 Minecraft，目标是「专业且易用」——既给得起专业工作流的深度，又让玩家零门槛上手。

🎬 时间轴 = Premiere / Blender

  • 多轨道剪辑（场景 / 相机 / 音频 / 标记）
  • 播放头精确定位、拖拽剪辑块
  • 右键拆分、波纹删除、变速编辑

🎥 相机 = Replay / 运镜

  • 推拉摇移、轨道、变焦等专业运镜
  • 相机走位作为独立轨道编辑
  • 实时 3D 预览即所见即所得

📈 关键帧 = 曲线编辑器

  • 位置 / 旋转 / 缩放 / 轨迹关键帧
  • 线性、缓入、缓出、贝塞尔插值
  • 对标专业关键帧曲线调节

🖥️ HTML 编辑器 = 现代 UX

  • MCEF/Chromium 全屏 HTML 界面
  • 悬停高亮、原生级新建对话框
  • Java↔JS 桥接，44 个 gip 图标接入
这是 Mod 还是独立软件？
是 Minecraft 26.2（Fabric）模组，继承自 McHorse 的 BBS，由 LingFengCW 维护并迁移到新版本。编辑器在游戏内以全屏 HTML 界面运行。
需要联网或额外运行环境吗？
不需要。MCEF 自带 Chromium 内核，整站与编辑器均为本地运行、无外部依赖。本宣传站同样纯静态、可双击打开。
和原版 BBS 有什么区别？
已迁移到 MC 26.2 / Fabric，并重做了 HTML 编辑器（DCC 暗色风、现代化时间轴与对话框），强化实时预览播放与相机驱动。
新手从哪开始？
先点上方「开始引导」认识界面，再读 完整教程：从场景/角色新建，到时间轴剪辑与动作序列预览。
