## 主菜单按钮全屏修复(最终版) + 版本号自动递增恢复

### 按钮全屏的真正根因(反汇编 26.2 字节码最终确认)
- SpriteIconButton 12 参构造器: (width, height, message, spriteWidth, spriteHeight,
  spriteOffsetX, spriteOffsetY, sprites, onPress, tooltip, narration, flag)
- **参数 1/2 是 width/height, 不是 x/y!** x/y 被硬编码为 0 (父类 AbstractButton
  构造器 (0,0,width,height,msg,onPress,narr))
- 之前传 (x, y, ...) → 按钮宽高 = 屏幕坐标(如 838x464) → 全屏覆盖
- 上一轮修 this.width=16 后用户仍全屏 → 可能渲染用构造时宽高或未重新构建

### 修复(提交 79e0aa3, Mod Menu 同款)
- ProjectsIconButton 改静态工厂 create(x,y):
  SpriteIconButton.builder(msg, onClick, true)  // 3参才返回 SpriteIconButton.Builder
  .size(16,16).sprite(sprites,16,16) 分步调用(链式会因泛型父类丢失类型)
  build() + setPosition(x,y)
- 注意: 2 参 builder() 返回 Button.Builder, 3 参(iconOnly=true)才是 SpriteIconButton.Builder

## Ultralight HTML UI 集成（提交后, 2.0.167, BUILD SUCCESSFUL）

### 依赖
com.labymedia:ultralight-java-base:0.4.12 (LabyMod central, 已打包进 mod)
SDK natives: 用户提供（放 gameDir/bbsnext/ultralight/）

### 核心文件
- UltralightUI.java: init(加载 natives) → createView(w,h) → render() → 纹理上传
  - natives: 1) gameDir/bbsnext/ultralight/ 2) classpath 提取
  - 渲染: BGRA→RGBA→GL11.texImage2D→batcher.texturedBox
  - 输入: fireMouse(type, x, y, button)
- UIUltralightOverlay.java: 全屏覆盖层（菜单入口切换）

### API 方法论（LabyMod ultralight-java-base 0.4.12）
- UltralightJava.load(Path) 加载 natives
- UltralightRenderer.create() → createView(long, long, config) → update() → render()
- UltralightView.surface() → lockPixels()→ByteBuffer → unlockPixels()
- OperatingSystem.get() 枚举判断平台（不支持。改用 System.getProperty）
- UltralightMouseEvent() 无参 + .type().x().y().button() fluent
- 枚举常量: DOWN/UP/MOVE, LEFT/RIGHT/MIDDLE

### 体积
mod jar (含 ultralight-java-base): ~8MB
SDK natives (win-x64): ~30MB → 运行时外挂
总计 <50MB ✅

### 运行条件
需下载 Ultralight SDK 将 bin/ 内容放入 gameDir/bbsnext/ultralight/：
UltralightCore.dll, WebCore.dll, Ultralight.dll + resources/
