## 全屏修复: 删偏方, 改用 MCEF 正经 resize 方案

### 教训(用户指出)
之前全屏消失我用了 `glfwGetWindowMonitor` 检测 + 关掉重建 browser 的偏方。
用户要求: 未知 API/技术先上网搜成熟方案, 不要自己反向工程瞎搞。

### 搜到的正经方案(已验证)
- DeepWiki(montoyo/mcef): CefBrowserOsr 的 `resize()` 会通知 CEF `wasResized()`,
  下次 `onPaint()` 触发**全量纹理重新分配**。窗口/全屏尺寸变化只要调 `browser.resize(w,h)` 即可。
- 现成 mod **BrowserMCEF**(基于同款 dimaskama/mcef) 明确支持浏览器内 F12 全屏 + PiP,
  证明 MCEF 在 MC 26.2 全屏下能正常工作 → 默认/边框式全屏 GL 上下文是保留的。
- 反汇编确认 dimaskama 的 CefRenderer **无上下文丢失处理**(只 GenTextures on init / DeleteTextures on cleanup)。

### 修复 (2.0.198)
- UIOverlay: 删除 monitor 重建偏方(Glfw 检测 + close/recreate), 删除 GLFW import
- syncSize 改为每帧比对 `Minecraft.getWindow().getGuiScaledWidth/Height()`,
  变化时调 `MCEFUI.resizeBrowser(gw, gh)` (→ browser.resize(scale(gw), scale(gh)))
- createBrowser/resizeBrowser 早已正确调 `browser.resize()`, 桥(console 通道 BBS_ACTION)正常

### 结论
全屏 = 窗口尺寸变化, 正经做法就是 resize。MCEF 纹理靠 resize 触发重分配, 不需要重建 browser。
若用户仍报独占式全屏(上下文真丢失)失效, 再考虑加 context-restore 监听重建。

## 盔甲/物品: 按用户要求先搜 API 再接 (2.0.199)

### 用户澄清
- "盔甲"在 BBS 里**不是独立 form**, 是角色(actor)的装备槽。原版 asset bin 只有 场景/角色。
- 要求: 砍掉"新建盔甲"思路, 改成"新建物品"; 物品能选已有 MC 物品、装配到角色身上(头/胸/腿/脚/手)。
- 角色肢体关键帧/背包循环动画/导入导出 = BBS 原生能力(建角色即有), 不重造。

### 搜到的正经 API(Fabric 1.20.4 Yarn 映射)
- 物品取用: `BuiltInRegistries.ITEM.get(Identifier.parse(id)).orElseThrow().value()` → `Item`
  (注意: 本版 `.get()` 返回 `Optional<Reference<Item>>`, 不是直接 `Item`, 直接 `new ItemStack(get(...))` 编译不过)
- 给角色穿装备 = 在 `replay.keyframes` 的 `KeyframeChannel<ItemStack>` 上 `insert(tick, ItemStack)`:
  `armorHead / armorChest / armorLegs / armorFeet / mainHand / offHand`
  (ActionPlayer.apply 播放时读这些轨道给 ActorEntity.setItemSlot)
- ItemForm 用 `ValueItemStack stack`, `stack.set(ItemStack)` (继承 BaseValueBasic.set)
- 关键类包: `mchorse.bbs_mod.forms.forms.ItemForm`, `mchorse.bbs_mod.film.replays.ReplayKeyframes`,
  `mchorse.bbs_mod.utils.keyframes.KeyframeChannel`, `net.minecraft.resources.Identifier`(非 ResourceLocation)

### 改动
- EditorBridge: 加 `newItem`(建 ItemForm replay) + `equip`(按 slot 在 keyframes 轨道 insert 当前帧)
- editor_ui.html: 右键"新建项"加"物品"; 素材箱头部加"装备"按钮; 点角色选中, 弹 6 槽装备编辑器(装配/清除, datalist 候选物品)

### 限制(已告知用户)
浏览器 overlay 无法渲染 MC 物品 3D 预览, 故用"文本输入物品 id + 候选 datalist + 选槽装配"替代
用户描述的"拖到角色 + 3D 预览弹窗"交互; 功能等价(选物品→选槽→装配到角色当前帧)。
