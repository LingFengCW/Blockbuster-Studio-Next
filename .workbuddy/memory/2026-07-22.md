# 2026-07-22 — BBS (bbs-next) 1.20.4→26.2 移植修复

## 任务
作为移植检测/修复方，修复小明遗留的 5 处 26.2 渲染管线问题。目标环境：MC 26.2 / yarn 26.2-snapshot-8+build.7 / fabric-api 0.153.0+26.2 / Java 25 / productionNamespace='named'。

## 已修复（全部为真实实现，无 TODO/空壳）
1. **玩家变身透明** — `PlayerRendererMixin.onSubmit` → `MorphRenderer.renderPlayer(...)` → 经 `context.withRenderContext(collector, cameraState)` 走 `EntityRenderDispatcher.extractEntity/submit` 实时提交管线。（PlayerRenderer 在 26.2 已移除，统一走 LivingEntityRenderer.submit）
2. **Mob 不穿装备** — `MobFormRenderer` 用 `setEquippedItem(EquipmentSlot, ItemStack)` 取代已删除的 `setItemSlot`。
3. **手持物品不显示** — `ModelFormRenderer.renderItems` 改用 26.2 提交式物品管线：`ItemModelResolver#updateForTopItem(state, stack, mode, world, null, 0)`（6 参，无 leftHand）+ `ItemStackRenderState#submit(pose, collector, light, overlay, 0)`。仅在 world 路径（collector!=null）生效，UI/第一人称手臂路径跳过。
4. **自定义物品紫黑块** — 新建 `ModelBlockSpecialRenderer` / `GunSpecialRenderer`（实现 `SpecialModelRenderer<ItemStack>`，含 `MAP_CODEC = MapCodec.unit(new Unbaked())`）；`BBSModClient` 用 `SpecialModelTypes.ID_MAPPER.put(...)` 注册；物品 JSON 改为 `{"model":{"type":"minecraft:special","base":"bbs:item/model","model":{"type":"bbs:model_block"}}}`。
5. **UI 预览实体不可见** — `MobFormRenderer.renderInUI` 现自建 `SubmitNodeStorage`（实现 SubmitNodeCollector）+ `CameraRenderState`（`mainCamera().extractRenderState(state, 0F)`），走 `extractEntity/submit/renderAllFeatures`。GUI 正交投影在屏幕绘制时已绑定，实体落入 UI 框内。

## 关键 API 事实（均经 Web 验证，非反编译）
- `MultiBufferSource` 在 26.2 完全移除，改为 `SubmitNodeCollector`/`SubmitNodeStorage`/`FeatureRenderDispatcher` 提交式管线。
- `SubmitNodeStorage()` 无参构造，实现 `SubmitNodeCollector`；`renderAllFeatures(collector)` 渲染时投影来自当前活动渲染通道。
- `EntityRenderDispatcher.submit(EntityRenderState, CameraRenderState, double,double,double, PoseStack, SubmitNodeCollector)`。
- `GameRenderer.getFeatureRenderDispatcher()` / `getMainCamera()` 公开；代码库通用 `gameRenderer.mainCamera()`。
- `CameraRenderState` 标准构造：`new CameraRenderState()` + `Camera#extractRenderState(state, partialTick)`。

## 已知残留缺口（超出小明点名的 5 个问题，未处理）
- **BBS 自有几何 orphan 漏洞**：`CustomVertexConsumer`/`BufferBuilder` 在任何路径都未被 `build()`/`draw()` 提交（其 `draw()` 是空操作）。非 MobForm 的 BBS 表单（自定义模型网格、UI 表单）可能无法渲染。与问题 1/2/5 独立。
- **UI/第一人称手臂路径手持物品**：因 collector==null（该路径无 SubmitNodeCollector），Issue 3 的持有物品在 UI 预览与第一人称手臂中不显示（与 BBS 几何未在 UI 提交一致）。
