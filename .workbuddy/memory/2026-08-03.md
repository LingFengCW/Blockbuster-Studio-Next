## 光影系统恢复 + 渲染链修复（第二轮）

### 关键事实
- 26.2 正式版默认 OpenGL 后端（Vulkan 实验性），BBS 用 LWJGL GL 合法
- BBS 实际渲染路径：所有调用方传 program=null → CPU BufferBuilder + Draw.drawBuffer（26.2 GpuDevice/RenderPass），不走自建 GL shader

### 恢复内容
- Texture.java: 真实 GL 纹理（原版 LWJGL 实现），替代空壳
- ShaderProgram.java: GL20 编译 + #moj_import 递归展开（但当前无调用方，保留备用）
- Draw.drawBuffer: 新增 GpuTextureView/GpuSampler 重载，bindTexture("Sampler0")
- PipGeometry: bridgeView(Link)/bridgeSampler()（GL纹理→DynamicTexture→GpuTextureView）
- ModelInstance.render: 修复 7参重载用 program==null 覆盖 ui 参数 bug
- ModelVAO/ExtrudedFormRenderer/BillboardFormRenderer: 补真实绘制（之前填顶点不画）

### 关键 API（26.2 纹理绑定）
RenderPass.bindTexture("Sampler0", GpuTextureView, GpuSampler)
AbstractTexture.getTextureView()/getSampler()
RenderSystem.getSamplerCache().getClampToEdge(FilterMode.LINEAR)

### 遗留
- Framebuffer.java/FramebufferForm 仍是空壳（FBO 离屏渲染，需 GpuTexture 桥专项）
- VAO 体系(BOBJModelVAO GL 部分)仍是死代码，被 CPU 路径取代
- javap/strings 被桩拦截，用 Node 读 class 字符串验证 API 存在性
